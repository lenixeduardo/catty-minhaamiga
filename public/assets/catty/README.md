# Catty — asset provenance

Assets were restored using **only existing approved visual sources**. No generative artwork was introduced. The original five standalone WebP files are not present in repository history.

- `hero.webp`: screenshot crop of the approved hero with transparent UI areas; still a derivative raster, not an original isolated render.
- `card-happy.webp`, `card-wink.webp`, `cta.webp`: pixel crops of the approved Catty landing triptych, keeping their intended distinct facial expressions.
- Demo panels use the existing `public/catty.png` image directly, without creating duplicate bytes.

Source mockup is retained in the owner's personal asset library rather than published to the public repository. Keep this provenance if replacing extracts with originals later.
